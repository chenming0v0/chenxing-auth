# 个人信息页账户管理 UI 设计

## 目标

把 Passkey、TOTP、外部身份绑定和账户资料修改集中到 `/console/profile`。界面参考 New API 个人设置页的“账户管理”双 Tab 结构，但继续使用辰星 HUD 面板、色彩、图标和交互语言，不再新增独立“账户与安全”页面或导航入口。

## 页面结构

- 个人信息页顶部保留用户头像和身份摘要。
- 删除原“基本资料”卡片；显示名称与用户名移入“账户资料”弹窗，邮箱作为安全设置中的独立同级条目和弹窗。
- 用户摘要下方使用一个全宽 `HudPanel`，标题为“账户管理”。
- 面板内提供“账户绑定”和“安全设置”两个可键盘访问的 Tab。
- `/console/security` 与 `/settings/security` 仅作为旧地址兼容，渲染个人信息页；导航和账户菜单不再展示独立入口。
- 移动端保持单列，桌面端账户绑定项使用两列网格；所有操作按钮保留至少 44px 的可点击高度。

## 账户绑定

绑定列表由内建邮箱身份、`/api/v1/auth/external-providers` 和 `/api/v1/auth/external-identities` 合并生成。每个 provider 都通过同一个绑定项组件渲染，常见 provider 使用识别度更高的图标，未知 provider 回退到通用图标。

启用新的 OAuth/OIDC provider 后无需修改 JSX 即可出现绑定按钮；已绑定但 provider 后来停用的身份仍保留在列表中并允许解除绑定。

## 安全设置

- 账户资料：默认只显示显示名称、用户名摘要和“修改账户资料”按钮，点击后以 `HudPanel` 对话框编辑这两项；用户名变化时动态要求当前密码。
- 邮箱地址：与账户资料、密码、Passkey、验证器应用同级，展示当前邮箱和验证状态；“更改邮箱”打开独立 `HudPanel` 对话框，要求新邮箱与当前密码。后端 Issue #559 接入前不提交未知字段，也不提示虚假成功。
- 密码：在当前行展开现有密码修改表单。
- Passkey：显示凭据数量，支持注册或继续添加 Passkey；已有凭据时保留“移除全部”操作。
- 验证器应用：未启用时提供“绑定验证器”，点击后在当前行展开二维码、手动密钥和 6 位确认码表单。
- 移除 Passkey/TOTP 和解除外部身份继续使用密码重新认证对话框及现有 CSRF 约束。

## 后端边界

临时 mock 只用于前端视觉验收，不代表后端完成。真实联调由 GitHub Issues #555（TOTP）、#556（Passkey）、#557（外部账户绑定）、#558（用户名修改）以及邮箱修改 Issue 跟踪；任何契约变化都必须同步 `openapi.yaml`。

## 验证

- Vitest 覆盖个人页不再显示“基本资料”、安全 Tab 资料摘要与编辑弹窗、动态 provider、TOTP、CSRF、绑定与解除绑定。
- Vite 构建同步 `web/dist`。
- 浏览器在桌面与 375px 视口检查布局、按钮可见性、用户名重新认证状态、无横向溢出和 TOTP 展开状态。
